# Интеллектуальные функции

## Режим A — базовый офлайн-помощник (работает всегда)

Без языковой модели. Источники выводов:

| Источник | Уровень достоверности |
|---|---|
| Правила диагностики (встроенный стартовый набор: общие определения кодов OBD-II SAE J2012 и типовые проверки; правила пользователя с обязательным источником) | «Требует проверки» — это гипотезы для конкретного автомобиля |
| Выданные заказ-наряды этого автосервиса с похожей жалобой/кодом | «Подтверждено (выполненный ремонт)» |
| Материалы библиотеки (полнотекстовый поиск) | статус материала, указанный пользователем |
| Запчасти каталога с записью применимости к этому авто | «Применимость подтверждена» / «Требует проверки» по записи |
| Нет подходящих данных | «Недостаточно данных» |

Запреты, реализованные в коде: помощник не создаёт артикулы и записи применимости, не предлагает запчасти без записи
применимости, не меняет склад и не проводит закупки. Для тормозов, рулевого, SRS, высоковольтных и топливных систем
выводится предупреждение о профессиональной проверке.

## Режим B — локальная языковая модель (подключается отдельно)

`ai/llm.py` — адаптер к серверу модели **на этом же компьютере** (Ollama или OpenAI-совместимый llama.cpp/LM Studio).
Адреса, кроме 127.0.0.1/localhost/::1, отклоняются; системный прокси не используется. Модель получает только контекст
режима A (правила, подтверждённые ремонты, фрагменты библиотеки) с нумерацией источников и инструкцией не придумывать
артикулы и параметры. Ответ всегда помечается «Требует проверки». Если модель не запущена — кнопка режима B
недоступна, причина показывается в интерфейсе.

### Выбор модели (требует проверки на оборудовании заказчика)

Модель не входит в установщик и не скачивается программой. Кандидаты для проверки (лицензии разрешают
коммерческое использование; указаны ориентировочно и подлежат проверке на момент выбора):

| Модель | Лицензия | Ориентировочные требования | Русский язык |
|---|---|---|---|
| Qwen2.5-7B-Instruct (квантизация Q4) | Apache 2.0 | ~8 ГБ ОЗУ, работает на CPU медленно | хорошо |
| Llama 3.1 8B Instruct (Q4) | Llama 3.1 Community License | ~8 ГБ ОЗУ | удовлетворительно |
| Mistral 7B Instruct v0.3 (Q4) | Apache 2.0 | ~8 ГБ ОЗУ | слабее |

Порядок приёмки режима B: установить сервер и модель на целевой компьютер → «Настройки → ИИ и распознавание →
Проверить модель» → прогнать 10–20 реальных обращений → оценить скорость и качество → принять или отказаться.

## Распознавание накладных

* PDF с текстовым слоем — `pypdf`; Excel/CSV — по строке заголовков (Наименование, Количество, Цена, Сумма, Артикул).
* Сканы и фото — Tesseract OCR, если установлен (`C:\Program Files\Tesseract-OCR` или папка `ocr` программы). Страницы
  PDF растеризуются средствами Qt.
* Проверки: арифметика строк, сумма строк против итога, номер документа, поставщик, дубль файла (SHA-256), дубль
  документа поставщика. Сопоставление с каталогом — только по артикулу (основному, альтернативному, поставщика);
  совпадение по названию — лишь подсказка с пометкой «сомнительное».
* Результат — черновик закупки после подтверждения менеджером.

## Рекомендации по закупке

Учитываются: доступный остаток (с резервами), минимальный остаток, расход за 90 дней (продажи + выдачи в ремонт −
возвраты), нехватка под открытые заказ-наряды, срок поставки, последняя цена и поставщик. Формула:
`купить = минимум + расход/день × срок поставки + нехватка под ремонты − доступно` (округление вверх).
При истории менее 30 дней или менее 3 документов, либо без срока поставки — пометка «Недостаточно данных для прогноза».
