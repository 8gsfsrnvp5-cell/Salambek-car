# Руководство по резервному копированию

## Что входит в копию

Файл `AutoServiceAI-<вид>-<дата>.asbak` (zip) или `.asbak.enc` (зашифрованный):

* база данных — снимок через SQLite backup API (корректная копия работающей базы, проверенная `integrity_check`);
* все вложения (оригиналы накладных, документы библиотеки, фото, логотип);
* настройки (хранятся в базе);
* `manifest.json` — версия программы и схемы базы, дата, компьютер, SHA-256 каждого файла.

Рядом сохраняется `.sha256` с контрольной суммой всего файла.

## Расписание (пока программа запущена)

| Когда | Что | Куда |
|---|---|---|
| Каждые 2 часа (настраивается) | Локальный снимок | `C:\ProgramData\AutoServiceAI\backups\local` (хранится 24 последних) |
| Ежедневно | Копия на внешний диск | Папка из настроек (хранится 30 последних) |
| Еженедельно | Проверка последней копии | Результат — в истории копий |
| Ежемесячно | Напоминание сделать дополнительную копию на другой носитель | — |

Если компьютер был выключен, пропущенные задачи выполняются при следующем запуске программы. Если внешний диск не
подключён или на нём мало места, программа показывает предупреждение, а в истории копий появляется запись с ошибкой.

## Ручная копия

**Настройки → Резервное копирование → Создать копию сейчас**: локальная папка, внешний диск или любая папка.
Флажок «Зашифровать паролем» — для копий, которые хранятся вне автосервиса.

## Шифрование

* AES-256-GCM, ключ получается из пароля (scrypt). Пароль нигде не хранится в открытом виде.
* Для копий по расписанию пароль задаётся кнопкой «Задать пароль шифрования…» и сохраняется защищённым средствами
  Windows (DPAPI) — расшифровать его можно только на этом компьютере под этой учётной записью.
* **Если пароль утерян, зашифрованную копию восстановить невозможно.** Запишите пароль и храните отдельно.

## Проверка копии

**Проверить копию…** — сверка контрольных сумм, целостность архива, проверка базы внутри копии и совместимости версии.

## Восстановление

Только администратор: **Восстановить из резервной копии…** → файл → пароль копии (если зашифрована) → пароль
администратора. Перед заменой текущая база сохраняется в `backups\local\before-restore-<дата>.db`. Копия, созданная
более новой версией программы, не восстанавливается — сначала обновите программу.

## Рекомендации

* Держите минимум два внешних носителя и меняйте их; один храните вне автосервиса.
* Раз в месяц проверяйте восстановление на другом компьютере (см. `INSTALL.md`, «Перенос»).
