# Сборка установщика AutoServiceAI-Setup.exe

Цепочка: исходный код → чистое окружение → автотесты → PyInstaller (папка с программой и всеми библиотеками,
включая Python и Qt) → Inno Setup (64-битный установщик на русском языке).

## Локально на Windows

1. Python 3.12 и Inno Setup 6: `winget install JRSoftware.InnoSetup`.
2. Из корня репозитория:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\build.ps1
   ```
3. Результат: `installer\Output\AutoServiceAI-Setup.exe` и файл контрольной суммы `.sha256`.

Скрипт создаёт `.venv-build` только с зависимостями программы, прогоняет тесты, собирает программу и установщик.
Если тесты не пройдены — установщик не собирается.

## Автоматически в GitHub Actions

Файл `.github/workflows/build.yml`, запускается при каждом push в `main`, для pull request и вручную:

1. автотесты;
2. сборка PyInstaller и Inno Setup на `windows-2022`;
3. **проверка установщика на чистой машине сборки**: тихая установка → запуск установленной программы с
   `--self-test` (без Python в PATH) → создание «рабочей» базы → установка обновления поверх → проверка, что база не
   изменилась и сделана её копия → повторная самопроверка → удаление → проверка, что данные остались;
4. артефакт **AutoServiceAI-Setup** (скачивается со страницы запуска в разделе Actions);
5. для тегов `v*` — релиз GitHub с установщиком.

Отдельное задание `audit` проверяет зависимости на известные уязвимости (`pip-audit`).

## Подпись кода и Smart App Control

Установщик и программа **не подписаны** цифровой подписью. Последствия:

* Windows SmartScreen покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
* На компьютерах, где включён **«Интеллектуальный контроль приложений» (Smart App Control)** Windows 11, неподписанные
  программы блокируются полностью, без возможности запуска. Варианты: подписать установщик и `AutoServiceAI.exe`
  сертификатом подписи кода (OV/EV или Microsoft Trusted Signing) — **требуется решение и участие заказчика**;
  либо отключить Smart App Control на компьютере автосервиса (Параметры → Конфиденциальность и защита → Безопасность
  Windows → Управление приложениями и браузером).

После получения сертификата подпись добавляется в `scripts/build.ps1` (signtool) и в workflow.

## OCR в составе установщика (необязательно)

Если перед запуском Inno Setup положить Tesseract OCR (Apache 2.0) с языками `rus` и `eng` в `build\ocr\`
(`tesseract.exe`, DLL, папка `tessdata`), он будет включён в установщик и программа найдёт его автоматически.
По умолчанию OCR не включается: программа сообщает, что распознавание сканов недоступно, а PDF с текстом и Excel
распознаются без OCR.
