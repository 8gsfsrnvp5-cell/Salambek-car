# Установка AutoService AI на компьютер автосервиса

Требования: 64-битная Windows 11 (Windows 10 версии 1809 и новее — допускается, проверяйте на конкретном компьютере),
4 ГБ ОЗУ, 1 ГБ свободного места. Интернет не нужен — ни для установки, ни для работы.

## Установка

1. Скопируйте `AutoServiceAI-Setup.exe` на флешку и перенесите на компьютер автосервиса.
2. Запустите установщик (потребуются права администратора Windows). Если появится окно SmartScreen —
   «Подробнее» → «Выполнить в любом случае» (установщик не подписан цифровой подписью, см. `BUILD.md`).
3. Пройдите мастер: папка установки, ярлык на рабочем столе. Python, Git и другие программы не нужны.
4. Откройте **AutoService AI** с рабочего стола. При первом запуске база создаётся автоматически; создайте учётную
   запись администратора и, при желании, менеджера.

Рабочие данные хранятся в `C:\ProgramData\AutoServiceAI` (у пользователей Windows есть права на изменение этой папки).

## Обновление

Запустите установщик новой версии поверх установленной. Перед обновлением установщик копирует базу в
`C:\ProgramData\AutoServiceAI\backups\before-update`, а программа при первом запуске обновляет структуру базы (тоже
с копией). Если обновление базы не удалось, база возвращается к исходному состоянию, программа сообщает об ошибке.
Данные не удаляются.

## Удаление

«Параметры Windows → Приложения → AutoService AI → Удалить». Программа удаляется, **папка данных остаётся**.
Удалите её вручную только если данные точно не нужны (сначала сделайте резервную копию).

## Перенос на другой компьютер

1. На старом компьютере: **Настройки → Резервное копирование → Создать копию сейчас** → «Другая папка…» → флешка или
   внешний диск. При желании включите шифрование паролем — запишите пароль.
2. На новом компьютере: установите программу, создайте временного администратора.
3. **Настройки → Резервное копирование → Восстановить из резервной копии** → выберите файл `.asbak` / `.asbak.enc`,
   при необходимости введите пароль копии и пароль администратора.
4. Программа перезапустится; войдите учётной записью **из восстановленной базы** (старые логин и пароль).

## Проверка установленной программы

Командная строка: `"C:\Program Files\AutoService AI\AutoServiceAI.exe" --self-test C:\temp\report.json` — проверка
работает во временной папке и не затрагивает рабочую базу; результат — в `report.json` (`"ok": true`).
