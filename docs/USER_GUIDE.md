# Руководство менеджера AutoService AI

Программа работает без интернета. Все суммы считаются автоматически; менеджер проверяет и подтверждает операции.

## Первый день работы

1. **Настройки → Автосервис**: название, ИНН, адрес, телефон, логотип (печатается только заполненное).
2. **Настройки → Цены и налоги**: стандартная наценка (например, 30 %), стоимость нормо-часа (если нужна), режим НДС.
3. **Настройки → Сотрудники**: механики.
4. **Склад → Поставщики**: поставщики (ИНН и срок поставки помогают распознаванию накладных и рекомендациям).
5. **Склад → Каталог**: карточки запчастей (вручную или «Импорт справочника» из Excel/CSV).
6. Начальные остатки: выберите запчасть → **Начальный остаток** → количество и себестоимость единицы
   (если себестоимость неизвестна — оставьте пустой: прибыль по этим единицам не будет показываться).
7. **Настройки → Резервное копирование**: укажите папку на внешнем диске.

## Наценка

Цена = себестоимость × (1 + наценка/100), от 0 до 100 %. Где задаётся (по приоритету):
в строке продажи/заказ-наряда → в партии закупки → в карточке запчасти → стандартная. В окне строки видно
себестоимость, наценку, цену и прибыль до проведения.

## Закупка

**Закупки → Новая закупка** → поставщик и номер его документа → «Добавить строку» (запчасть, количество, цена, при
желании наценка партии) → **Провести закупку**. Доставку можно указать в реквизитах — она распределится в себестоимость.
Повторно ввести тот же документ поставщика программа не даст. Ошибочную закупку отменяет администратор (если товар
ещё не расходовался), иначе — «Возврат поставщику».

### Распознавание накладной

**Распознать накладную** → PDF, Excel или скан. Программа сохраняет оригинал, извлекает реквизиты и строки,
проверяет арифметику, сопоставляет артикулы с каталогом. Красным/оранжевым отмечено всё сомнительное: несошедшаяся
арифметика, совпадение только по названию, не найденные позиции. Выберите или создайте запчасти, исправьте значения
по оригиналу → **Создать черновик закупки** → проверьте → **Провести закупку**. Без вашего подтверждения склад
не меняется. Сканы распознаются, только если установлен Tesseract OCR (см. «Настройки → ИИ и распознавание»).

## Продажа

**Продажи → Новая продажа** → «Добавить запчасть» (только из наличия) → количество и наценка → **Провести продажу**
(выберите способ оплаты или «в долг»). Печать: «Документ продажи» или «Квитанция (чек)» для чекового принтера
(нефискальная). Возврат — «Возврат от покупателя» с возвратом денег.

## Автомобиль и заказ-наряд

1. **Автомобили → Новый автомобиль**: достаточно марки; госномер, VIN, клиент — по возможности (программа предупредит
   о неполной карточке). Поиск — по госномеру (в т.ч. прежнему), VIN, марке, клиенту, телефону, номеру заказ-наряда.
2. **Ремонты → Новый заказ-наряд** → автомобиль → пробег, жалоба. Видны предыдущие обращения.
3. Вкладка **Работы**: работы с ценой; отметьте выполненные. Подсказки берутся из истории.
4. Вкладка **Запчасти**: «Добавить запчасть» — резервируется сразу; при установке — **Выдать со склада** (списание
   FIFO). Неиспользованное — «Вернуть на склад».
5. **Документы**: предварительная смета, заказ-наряд, акт, квитанция, список установленных запчастей, накладная.
6. Статусы: Новый → Диагностика → Ожидает согласования → Ожидает запчасти → В ремонте → **Готов** (все работы выполнены,
   запчасти выданы) → **Выдан**. «Выдан» не означает «оплачен» — оплаты на вкладке **Оплаты** (частичные допускаются).

## Склад

* **Остатки**: остаток, резерв, доступно, себестоимость; оранжевым — ниже минимального остатка.
* **Инвентаризация**: новая → ввод фактических остатков → «Провести» (недостачи списываются, излишки приходуются).
* **Списание / оприходование** — с указанием основания. Все движения сохраняются в истории.

## ИИ-помощник

Введите автомобиль, жалобу, коды ошибок и результаты диагностики → **Проанализировать**. Программа покажет:
возможные причины (гипотезы, «Требует проверки»), порядок проверок, подтверждённые ремонты из истории сервиса,
материалы библиотеки, запчасти из каталога с указанной применимостью, каких данных не хватает. Для тормозов, рулевого
и других систем безопасности — предупреждение о профессиональной проверке. Помощник ничего не заказывает сам: можно
подготовить **черновик закупки**. Вкладка «Рекомендации по закупке» — что заканчивается и сколько купить с основанием расчёта.

## Отчёты и финансы

**Отчёты**: 15 отчётов с фильтрами, выгрузка в Excel/CSV/PDF и печать. **Финансы** (администратор): сводка, платежи,
расходы, долги клиентов и поставщикам. Ошибочный платёж или расход отменяется с причиной — запись остаётся в истории.

## Если что-то пошло не так

* Сообщение об ошибке объясняет причину (например, «Недостаточно товара … доступно 2 с учётом резервов»).
* Ошибочные проведённые операции не удаляются — их отменяет администратор с указанием причины.
* Журнал программы: **Настройки → О программе → Открыть журнал**.
